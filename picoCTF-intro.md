# picoCTF Write-ups 🚩

This section of the repository contains my write-ups for **picoCTF challenges**, completed as part of hands-on cybersecurity learning and practice.

picoCTF is a beginner-friendly Capture The Flag (CTF) platform that introduces core security concepts such as Linux command-line usage, web fundamentals, cryptography, and basic exploitation techniques.

The goal of these write-ups is not competition, but to:
- Understand how each challenge works
- Practice using common security tools and commands
- Build a strong foundation for more advanced cybersecurity topics
- Document lessons learned in a clear and structured way

Difficulty and challenge complexity increase progressively as skills develop.
